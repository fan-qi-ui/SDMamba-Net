MCFBR 多尺度通道融合与边界细化解码器说明书

一、说明对象与文章依据
本说明书对应 MCFBR.zip。MCFBR 的英文全称为 Multi-scale Channel Fusion and Boundary Refinement Decoder。
内容依据 SDMamba-Net1114.docx 第 3.1、3.4 节及图 2、图 5，并结合本次压缩包中的实际源码编写。
文章中的 MCFBR 是 SDMamba-Net 的解码部分，用于将编码器四阶段特征恢复为像素级裂缝预测。代码保留原工程的 SRFModule 类名，MCFBR 是本文中的结构名称。

二、设计目的与工作原理
该解码器面向裂缝宽度变化、跨层信息融合不足和边缘细节恢复困难的问题，结合浅层定位信息与深层上下文。
处理流程为：
1. 通道对齐：四级编码特征分别经过线性投影、逐点卷积与组归一化，映射到统一的中间通道数。
2. 浅层引导：由第一层特征生成单通道空间门控；其他三层先对齐到浅层分辨率，再由同一门控调制。第一层保留直接的信息路径。
3. 尺度对齐：四个分支分别上采样至目标输出尺寸，并沿通道维拼接。
4. 多尺度建模：拼接特征经过膨胀率为 1、2、3 的并行深度卷积，再进行通道融合，兼顾细小裂缝和较宽邻域。
5. 通道融合与细化：使用逐点卷积组合跨层信息，经 BoundaryRefine 生成局部修正项并进行残差相加。
6. 像素预测：预测头将融合特征映射为单通道分割响应。

三、压缩包中的源码位置
source/models/decoder/SRF.py
  SRFModule：完整解码器。
  MLP、Conv2d_GN：特征投影与归一化。
  SRModule：浅层空间引导。
  MSDWConv：多尺度膨胀深度卷积。
  BoundaryRefine：局部残差细化。
  linear_pred：输出预测头。
reference/models/segmentor/MixerCSeg.py
  提供原工程中调用该解码器的位置，用于核对集成关系。
SOURCE_MANIFEST.json
  记录复制来源及 SHA-256 校验值。

四、输入输出与关键参数
输入为四个编码特征组成的列表，按由浅到深顺序传入；每个特征的格式均为 [B, C, H, W]。
论文网络四阶段通道为 [16, 32, 64, 128]，空间尺度为输入图像的 1/4、1/8、1/16、1/32。
当前原工程使用 mid_dim=8；目标输出尺寸由 size 参数指定。
以 512×512 输入为例，四级特征为：
  [B, 16, 128, 128]
  [B, 32, 64, 64]
  [B, 64, 32, 32]
  [B, 128, 16, 16]
对应输出为 [B, 1, 512, 512]。输出是 logits，转成概率时需要执行 sigmoid。

五、完整结构的配置与使用
依赖：PyTorch。解压后可使用 requirements.txt 记录的依赖信息。
构造解码器前设置 MIXER_DECODER_VARIANT=full，确保启用多尺度卷积、通道融合和边界细化。
MIXER_DECODER_VARIANT=shallow 是消融分支，不等同于本文完整 MCFBR。
以下示例在解压后的 MCFBR 文件夹内运行；通过文件加载源码，避免导入原工程 models 包时触发无关依赖。

from pathlib import Path
import importlib.util

def load_source(relative_path, module_name):
    spec = importlib.util.spec_from_file_location(module_name, Path(relative_path))
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module

import os
import torch
os.environ['MIXER_DECODER_VARIANT'] = 'full'
srf = load_source('source/models/decoder/SRF.py', 'mcfbr_source')
decoder = srf.SRFModule([16, 32, 64, 128], mid_dim=8, size=(512, 512)).eval()
features = [torch.randn(1, c, s, s) for c, s in
            [(16, 128), (32, 64), (64, 32), (128, 16)]]
with torch.no_grad():
    prediction = decoder(features)  # [1, 1, 512, 512]，未经过 sigmoid 的输出
