SEMM 频谱增强 Mamba 混合模块说明书

一、说明对象与文章依据
本说明书对应 SEMM.zip。SEMM 的英文全称为 Spectral-Enhanced Mamba Mixing。
内容依据 SDMamba-Net1114.docx 第 3.1、3.2 节及图 2、图 3，并结合本次压缩包中的实际源码编写。
SEMM 位于每个编码阶段中，先完成频域细节补充与上下文混合，再将特征交给 DASR 进一步细化。

二、设计目的与工作原理
该模块针对细弱裂缝局部响应不足、细长结构依赖远距离上下文以及局部和全局信息难以协同的问题，将以下操作按顺序组合。
1. 频域高频增强 FHE：对特征进行组归一化和二维实数快速傅里叶变换。使用具有可学习截止频率的平滑高通权重筛选频谱，经逆变换恢复空间细节，再通过深度卷积、逐点投影和输入门控，以残差方式补充原特征。
2. 四方向选择状态建模：将特征按行优先、列优先及其逆向组织成四条扫描序列。由输入生成相关状态更新参数，通过选择性状态递推汇聚跨位置上下文。
3. 有效步长引导的全局与局部混合：根据有效步长对方向—通道响应进行分组。全局分支建立显式注意力交互，局部分支补充邻域响应和门控调制，再按索引回填到原方向—通道位置。
4. 空间恢复与输出：对四方向结果逆扫描并在空间坐标上合并，经输出门控、投影、残差连接和前馈网络得到结果。
FHE、Mamba 状态递推与显式注意力分别提供频谱细节、递归上下文和直接特征交互。高频增强本身并不等同于裂缝筛选，背景纹理也可能产生高频响应。

三、压缩包中的源码位置
source/models/layers/freq_sparse.py
  FrequencyHighEnhancement：FHE。
source/VMamba/models/vmamba.py
  SS2D、SS2Dv2.forward_corev2：选择状态扫描及全局/局部混合。
  TransMixer：归一化、状态混合、输出与残差、前馈网络等组合。
source/VMamba/models/csm_triton.py
  四方向扫描与合并相关实现，包含 PyTorch 回退实现。
source/VMamba/models/csms6s.py
  selective scan 相关实现及可选 CUDA 后端调用。
source/VMamba/models/utils.py 及其他附带 VMamba 源码
  提供原实现依赖的辅助模块。
source/VMamba/models/kernels/selective_scan/
  可选 CUDA 扩展的构建源码。
reference/models/encoder/vss_block.py
  fhe_mamba_gl 分支展示完整 SEMM，即 FrequencyHighEnhancement 后接 TransMixer。
reference/models/segmentor/MixerCSeg.py
  提供原工程的四阶段模型参数。
SOURCE_MANIFEST.json
  记录复制来源及 SHA-256 校验值。
freq_sparse.py 原本同时定义 FHE 和 CCSA，因此保留完整文件；SEMM 使用其中的 FHE 类。

四、输入输出与当前实现参数
输入与输出均为 [B, C, H, W]，模块保持通道数与空间分辨率。
完整原工程四阶段通道为 [16, 32, 64, 128]，状态维度为 [8, 8, 16, 16]，每阶段 depth=1、mlp_ratio=2.0。
FHE 当前初始化 cutoff=0.18，temperature=18.0；可学习截止频率通过参数化限制在 0.05 至 0.45。
原代码初始高频残差缩放参数 gamma=0.1。
完整混合分支使用 channel_first=True、use_global_local=True。
上述数值来自当前源码；其中属于实现配置的数值不应当作文章对所有任务的固定要求。

五、依赖与使用方法
主要依赖：PyTorch、timm==0.4.12、fvcore、einops、packaging，详见 requirements.txt。
Triton 和 selective_scan CUDA 扩展用于可选加速；原源码包含未安装相应加速后端时的 PyTorch 回退。CUDA 扩展需匹配本机 PyTorch/CUDA 工具链。
在原完整工程中构造 VSS 前，设置 MIXER_SEMM_VARIANT=fhe_mamba_gl 可选择完整 SEMM；只保留 SEMM 时可同时设置 MIXER_DASR_VARIANT=none。
reference 是集成参考，直接运行其中的 VSS 仍需完整原工程依赖。
以下示例在解压后的 SEMM 文件夹内运行，先使用较小特征图验证接口；全局注意力的显存占用会随空间 token 数增加。

from pathlib import Path
import importlib.util

def load_source(relative_path, module_name):
    spec = importlib.util.spec_from_file_location(module_name, Path(relative_path))
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module

import sys
sys.path.insert(0, str(Path('source').resolve()))
import torch
from torch import nn
from VMamba.models.vmamba import TransMixer
freq = load_source('source/models/layers/freq_sparse.py', 'semm_frequency_source')
semm = nn.Sequential(
    freq.FrequencyHighEnhancement(dim=16, cutoff=0.18, temperature=18.0),
    TransMixer(hidden_dim=16, ssm_d_state=8, mlp_ratio=2.0,
               channel_first=True, use_global_local=True),
).eval()
# 先以较小特征图验证。全局注意力的内存开销随空间 token 数增加。
with torch.no_grad():
    output = semm(torch.randn(1, 16, 16, 16))  # [1, 16, 16, 16]
